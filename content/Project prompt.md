<Project-Description>
Eine Anwendung die folgendes macht: Man kann die Tabs aus seinem Browser mit der App synchronisieren. Dann lädt die App die Seiten herunter und stellt sie in einem vereinfachten Lesemodus dar.
Außerdem gibt es neben der Anzeige ein Editor um Markdown Notizen zu schreiben. Man kann Stellen auf der angezeigten Stelle markieren und als Zitate in die Markdown Notiz einfügen. Letztlich kann man die Markdown Notiz exportieren.
</Project-Description>
