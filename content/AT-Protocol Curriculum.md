- **Goals**: Understand what the AT Protocol is, its key components, and its goals.
- **Resources**:

### **Day 5-7: Core Components**

- **Goals**: Learn the architecture of AT Protocol and its main components.
- **Topics**:
    - **Lexicon**: Schemas for data interchange.
    - **Repository**: User-managed data store.
    - **Personal Data Servers (PDS)**: Data storage and sharing.
- **Resources**:
    - Read the AT Protocol Specs
    - Explore technical blog posts on Bluesky’s GitHub ([https://github.com/bluesky-social](https://github.com/bluesky-social))
- **Activities**:
    - Draft a glossary of key terms.
    - Build a simple diagram of the protocol flow.
